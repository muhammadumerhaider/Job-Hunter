# 💼 Job Hunter

A modern job search web app built with **React**, **Vite**, and the **JSearch API**, allowing users to browse job listings and view detailed job information with a clean, responsive UI.

---

## ✨ Features

- 🔍 Search jobs by keyword (e.g. "React", "Backend")
- 📃 View detailed job descriptions
- 🌐 Direct links to apply via publisher websites
- 📱 Responsive design for desktop and mobile
- 🔒 Environment variable protection for API keys

---

## 🛠️ Tech Stack

- **Frontend:** React + Vite
- **API:** [JSearch API (RapidAPI)](https://rapidapi.com/hub)
- **Styling:** Custom CSS 
- **State Management:** Context API

---

## 📦 Installation & Setup

```bash
# 1. Clone the repo
git clone https://github.com/your-username/job-hunter.git
cd job-hunter

# 2. Install dependencies
npm install

# 3. Create a .env file
cp .env.example .env
# Add your JSearch API key in .env file

# 4. Start the dev server
npm run dev
